A — Flat Join Table

One row per item×supplier pair. Original proposal. Simple but gets long fast — 50 items × 3 suppliers = 150 rows, hard to get a per-item overview.

item                  │ quotes │ best price │ status
▼ Valve XY23 (001)       │ 3      │ $42.00     │ awaiting

B — Item-Grouped (Recommended by Opus)

Parent row = item with summary (quote count, best price). Expand to see per-supplier detail. Scales to 500 items. Operator sees item-level status at a glance.

ITEMS
