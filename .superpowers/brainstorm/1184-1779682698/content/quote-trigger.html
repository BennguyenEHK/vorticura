Question 3 — Quotation Generation Trigger

When and how does the system move from items_ordering → quotation_processing?

STATUS BAR
Items ordered: 10/10 ✓ All complete
⚡ Quotation generation triggered automatically...
↳ No user action required

A — Auto-Trigger

System fires quotation when all items reach ordered. Zero clicks. Risk: fires before operator is ready to price; no margin review moment.

READINESS STRIP (top of panel)
📦 Quoted: 8/10 ⚠️ Declined: 1 ⏳ Awaiting: 1
Generate Quote →
↳ Button always visible; operator decides when ready

B — Explicit CTA + Readiness Strip ✦ Recommended

Persistent "Generate Quote" button with a live strip showing quoted/declined/awaiting counts. Operator decides when to proceed — even with 1–2 items still pending.

STATUS BAR
Quoted: 9/10 Coverage: 90%
Generate Quote (9/10 ready)
↳ Button unlocks at configurable threshold (e.g. 80%)

C — Threshold-Gated CTA

Button is disabled until ≥X% of items are quoted. Prevents premature quoting but blocks operator if 1 straggly supplier never replies.

Pick your trigger model — click in browser or reply in terminal.
